# Public SunCET assets

## `suncet_spacecraft.jpg`

SunCET spacecraft with deployed solar arrays during ground integration.

- Credit: SunCET/JHUAPL
- Public reuse: approved by the mission PI
- Repository preparation: resized to 1600 by 1200 pixels and re-encoded without
  the source photograph's EXIF, device, timestamp, or GPS metadata

The full-resolution mission source remains outside this software repository.
